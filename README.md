The program allows a user to select a pizza size, add optional toppings, and calculates the total cost of the order based on the user's choices.

## 🚀 How It Works

The program asks the user to:

1. Choose a pizza size.
2. Decide whether they want additional toppings.
3. Calculate the final bill based on their selections.
4. Display the total amount to the user.
